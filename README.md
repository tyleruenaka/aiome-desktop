# Aiome desktop

Downloads for the Aiome desktop app. This repo holds releases only; there is no code here.

- Mac (Apple Silicon and Intel): [Aiome-mac.dmg](https://github.com/tyleruenaka/aiome-desktop/releases/latest/download/Aiome-mac.dmg)
- Windows (64-bit): [Aiome-windows.exe](https://github.com/tyleruenaka/aiome-desktop/releases/latest/download/Aiome-windows.exe)

The app updates itself after it is installed.
